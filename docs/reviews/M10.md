### The public API it adds

Each goes into `docs/HOOKS.md` with `@since 1.0.0`, the snapshot and the changelog in the same commit.

- **Filters:** `cbuild_width_guide` (the guide's rows), `cbuild_start_button` (the kit, the place, the words, or off).
- **The route:** the arguments `from`, `q`, `sort`; the fields for looks, sizes, chips, the changed build and the currency settings.
- **Build link keys:** `_q`, and `_sort` if Sort travels in the link.
- **A spec key:** `bearings_included`.
- **Meta and schema:** `_cbuild_layout` and `schema/kit-layout.json`; `image` in `schema/kit-presets.json`; prices and currency in the saved build's picks document.
- **A block template,** registered for kit products.
- **CSS classes and custom properties** for the new layout's parts (stage, panel, rail, footer, chips, the size group). A documented class the new layout no longer prints stays on the element that takes its place, or is deprecated with a notice: nothing public is renamed or removed (CLAUDE.md asks Zach first).

The freeze follows: from 1.0.0, Semantic Versioning holds.
