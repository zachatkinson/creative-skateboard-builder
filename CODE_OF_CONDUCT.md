# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in its issues, pull requests and anywhere else the project's work is discussed.

In short: be kind and patient, assume good faith, and keep to the work. Harassment, personal attacks and unwelcome sexual attention or advances are not accepted, from anyone, in any form.

## Reporting

Report behaviour that breaks this code to the maintainers, privately, through this repository's **Security** tab (**Report a vulnerability**), which reaches the maintainers alone; say it is a conduct report. Reports are read by the maintainers only, and kept confidential.

## Enforcement

The maintainers decide what happens, following the Contributor Covenant's enforcement guidelines: a private word, a warning, a time out, or a ban, as the behaviour calls for.
